What is HTML?

HTML (HyperText Markup Language) is the standard markup language for documents designed to be displayed in a web browser.

What is CSS?

CSS (Cascading Style Sheets) is a style sheet language used for describing the presentation of a document written in an HTML or XML markup language.

What is Javascript?

Javascript is a programming language that is used to create interactive effects within web browsers.

What is Iframe?

An iframe is an HTML element that allows you to embed another HTML page within the current page.

What is Details Tag?

The details tag is used to create a disclosure widget in an HTML document.

What is Summary Tag?

The summary tag is used to define a visible heading for each details element.
